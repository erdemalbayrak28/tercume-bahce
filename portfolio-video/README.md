## Yeniden üretim

Kayıt: `node portfolio-video/capture.cjs`. Playwright'ın video kaydı için `PLAYWRIGHT_BROWSERS_PATH` bu klasörün `runtime` dizinine ayarlanmalıdır; `runtime/ffmpeg-1011/ffmpeg-win64.exe` gerekir. Chrome ve bundled Playwright konumları capture.cjs içinde tanımlıdır.

Render: `python portfolio-video/render.py`. Python Pillow, NumPy, PATH üzerinde FFmpeg/FFprobe ve Windows Segoe UI fontları gerekir.

Metinler, renkler, zamanlama ve cihaz çerçeveleri render.py içinden düzenlenebilir. Ham kayıtlar captures klasöründedir. Instagram'a yükleme yapılmadı.
